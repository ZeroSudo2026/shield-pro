## 🔍 Executive Summary
Modern web applications and internal server endpoints face constant brute-force and credential-stuffing attacks. Manual monitoring is inefficient and reactive. **Shield Pro V2.0** provides an automated, enterprise-ready Intrusion Prevention System (IPS) that detects attacks in real-time, updates Linux kernel firewall rules (`iptables`), and generates executive security audit logs.

1. **Immediate Threat Neutralization:** Integrates directly into the host OS firewall to issue instant `DROP` rules for malicious IP addresses.
2. **Zero-Configuration UI:** Standalone executable binary requiring no Python dependencies on target Linux nodes.
3. **Automated Compliance Audit:** Produces formatted, exportable PDF incident reports for IT managers.
